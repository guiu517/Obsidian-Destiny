1. 六甲分禄：
    
    1. 丙寅为福星禄，甲土克丙水为财，这里指的是真五行。甲来食丙，丙下寅为甲禄，食神又代表名声福气。故而丙寅叫福星禄，又叫名位禄。
    2. 戊寅为伏马禄，火土相生大吉，指的也是真五行。带刑杖，福祸相倚。
    3. 庚寅为破禄，半凶半吉。
    4. 壬寅为正禄，禄头带倒食，丁壬见寅卯为截路空亡煞，故说带截路空亡，容易成为僧人道士，有福。
    5. 甲寅为长生福星禄，大吉。
    6. 需要注意，以上六甲分禄没有针对到具体的甲子还是甲寅甲辰甲申等，还要结合气散气聚，五行生克，禄中有无刑冲害空等其余因素。所有的十干分禄均有考虑到这些因素影响。
    
2. 六乙分禄：
    
    1. 丁卯为截路空亡，丁壬见寅卯为截路空亡。乙真金，丁真木，二者不相喜，丁又败于卯，故凶。乙虽食丁，但不同于甲食丙寅，丁败于卯而丙生于寅之缘故。
    2. 己卯为进神禄，有官不久。己土气于卯的缘故。
    3. 辛卯为破禄，又为交神，有财不久。
    4. 癸卯为天乙死禄，壬癸见卯巳为贵神，壬癸水死于卯。虽贵终贫。
    5. 乙卯旺禄，乙旺于卯，喜神大吉。
    
3. 六丙分禄：
    
    1. 己巳为九天禄库，己见巳为禄九天，也叫禄库，有官。
    2. 辛巳为截路空亡，丙辛见辰巳为截路空亡，多是非。
    3. 癸巳为伏贵神禄，癸见巳为贵神，半吉，有成有财，也叫多成败。
    4. 乙巳为旺马禄，有官。
    5. 丁巳为旺库禄，有官。
    
4. 六丁分禄：
    
    1. 庚午为截路空亡禄，多成败。
    2. 壬午合禄，午中丁与壬有真木死于午，有官短命。
    3. 甲午为进神禄，有登科之喜。
    4. 丙午为喜神自刃禄，半吉半凶。
    5. 戊午伏羊刃禄，也是自刃禄，无喜神，多凶灾患。
    
5. 六戊分禄：
    
    1. 己巳为九天禄库，有官司。
    2. 辛巳为截路空亡禄，有官终无，多是非。
    3. 癸巳贵神禄，戊癸真火旺于巳，有官位重。
    4. 乙巳为驿马同乡禄，有官大吉。
    5. 丁巳为旺库禄，有官。
    
6. 六己分禄：
    
    1. 庚午为截路空亡禄，凶象。
    2. 壬午死鬼禄，又是飞刃禄，凶。
    3. 甲午为进神德合禄，大吉。
    4. 丙午为喜神羊刃禄，凶。
    5. 戊午为伏神羊刃禄，凶。
    
7. 六庚分禄：
    
    1. 壬申为大败禄，多贫贱。
    2. 甲申为截路空亡禄，凶。
    3. 丙申为大败禄，多成败，招是非。
    4. 戊申为伏马禄，多滞。
    5. 庚申为长生禄，大吉。
    
8. 六辛分禄：
    
    1. 癸酉为伏神禄，真气水火相犯，凶。
    2. 乙酉为破禄，多成败。
    3. 丁酉空亡贵神禄，吉凶交互。
    4. 己酉进神禄，大妙。
    5. 辛酉正禄。
    
9. 六壬分禄：
    
    1. 丁亥为贵神禄，有官。
    2. 乙亥为天德禄，大吉。
    3. 己亥为旺禄，吉。
    4. 辛亥为同马乡禄，大贵。
    5. 癸亥为大败禄，贫薄。
    
10. 六癸分禄：
    
    1. 甲子为进神禄，主登科进达之喜。
    2. 丙子交羊刃禄，此处为飞刃，带福星贵，有权。
    3. 戊子为伏羊刃合贵禄，半吉。
    4. 庚子为应禄吉。
    5. 壬子为正羊刃禄，凶。

---
同样的十干分禄，十干配支神不同则吉凶不同。如甲子见丙寅、甲寅见丙寅、甲戌见丙寅，三者五行生克，生旺死绝，刑冲合会，空与不空，诸般神煞各有不同。
