## 概述

- **鬼限**：指寿命之事，用于推论死亡之期，尤其指中年死亡之限。
- 核心思想：以 **年柱纳音五行** 为基准，对应一组忌见的干支或地支；若四柱、大运、流年中出现，即犯鬼限。

---

## 第一组查法：年柱纳音五行对应忌干支

> 《神白经》曰：  
> 火忌申酉亥（甲申、乙酉、癸亥）  
> 金嫌亥子丑（乙亥、戊子、己丑）  
> 水土寅卯巳（水忌庚寅、己卯、丁巳；土忌庚寅、辛卯、丁巳）  
> 木怕巳午申（辛巳、甲午、壬申）  
> 更苦逢阴鬼，寿算永不停。  
> 艰辛久住仕，发即祸来寻。
> 若人逢此地，不请怨天文。
> 谓之人适鬼门，气度萧闲。

整理成表格：

| 年柱纳音五行 | 忌见干支     |
| ------ | -------- |
| 火      | 甲申、乙酉、癸亥 |
| 金      | 乙亥、戊子、己丑 |
| 水      | 庚寅、己卯、丁巳 |
| 土      | 庚寅、辛卯、丁巳 |
| 木      | 辛巳、甲午、壬申 |

### 适用范围

1. 四柱八字本身出现忌干支（尤其 **时柱**）。
2. 大运、流年干支也属于此范围。

### 例一

**命：丙辰<sup>土</sup> 辛卯 癸卯 丁巳**

- 年柱丙辰，纳音为 **沙中土**。
- 土命忌：庚寅、辛卯、丁巳。
- 时柱为 **丁巳**，符合鬼限规则。

### 例二

**命：庚寅<sup>木</sup> 己卯 辛卯 甲午**

- 年柱庚寅，纳音为 **松柏木**。
- 木命忌：辛巳、甲午、壬申。
- 时柱为 **甲午**，符合鬼限规则。

### 例三：大运流年应用

**命：戊申<sup>土</sup> 癸亥 甲子 甲子**
运：甲寅 乙卯 丙辰 丁巳
年：庚寅
    并不只是四柱八字本身带鬼限，大运流年亦有鬼限。

- 年柱戊申，纳音为 **大驿土**。
- 土之鬼限：庚寅、辛卯、丁巳。
- 原局无，但大运有 **丁巳运**。
- 在丁巳运中，需注意流年是否再遇庚寅、辛卯、丁巳。若只有大运是丁巳，流年不再重遇，亦非鬼限之祸
- 在丁巳运中，四十三岁为庚寅，四十四岁为辛卯，四十三，四十四岁为鬼限流年。

## 另说

> 《五行精纪》曰：  
> 鬼限生来有所爱，欲知人死向斯求。
> 金哥出去休骑马，火弟归来莫跨牛。
> 木遇蛇蛇须走远，水逢鸡子也堪愁。
> 土人更切防猪兔，难保年老到白头。

此说以 **年柱纳音五行** 对查 **时支**（或大运流年地支）。

| 年柱纳音五行 | 忌见地支 |
| ------------ | -------- |
| 金 | 午 |
| 火 | 丑 |
| 木 | 子、巳 |
| 水 | 酉 |
| 土 | 卯、亥 |

### 例一

命：丙寅<sup>火</sup> 己亥 丁未 辛丑**
运：庚子 辛丑

- 年柱丙寅，纳音属 **火**。
- 火年忌 **丑**。
- 时支为 **丑**，犯鬼限。
- 大运又有 **辛丑运**，亦为鬼限运。
- 此造如果以很保守的立场而推论之，即是此命一生多小人，艰辛处世，可保永寿，设若一得荣华富贵，就百病丛生。

《玉照定真经》所云：“身命逢刑返克，而必须夭贱。”
    鬼限运其中的易理为有二：1.纳音返克。2.年命纳音五行在日时为病死绝地，故主夭贱。
