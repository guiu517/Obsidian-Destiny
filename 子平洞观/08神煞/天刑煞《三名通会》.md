
体弱多病 即：一辈子身上毛病不断，常年跟医药打交道，看病花钱多。但不是说一定会短命，只是病痛多。容易操心子女，为妻儿操劳，一生操心劳神。

### 判断口诀

子丑人己时，寅人庚时，卯辰人辛时，巳人壬时，午未人癸时，申人丙时，酉戌人丁时，亥人戊时。

| 出生年 | 时干  |
| --- | --- |
| 子、丑 | 己时  |
| 寅   | 庚时  |
| 卯、辰 | 辛时  |
| 巳   | 壬时  |
| 午、未 | 癸时  |
| 申   | 丙时  |
| 酉、戌 | 丁时  |
| 亥   | 戊时  |

补充：此神煞无甲己时干，如果八字天干透出甲、乙，就不用再看这个神煞。

> 命例：甲寅 戊辰 丙子 庚寅

---
《五行精纪·卷二十三·释凶神例》原文记载
    天刑：子丑人己时，寅人庚时，卯辰人辛时，巳人壬时，午未人癸时，申人丙时，酉戌人丁时，亥人戊时。
    犯之者遭刑，有疾，四时休败不利，四时旺者富也。

《三名通会·卷三·总论诸神煞》原文记载
    天刑煞，此煞取：子丑人乙时，寅人庚时，卯辰人辛时，巳人壬时，午未人癸时，甲人丙时，酉戌人丁时，亥人戌时。
    取时刑克本命，犯者遭刑有疾。

《三命通会》有云：“取时刑克本命。”当为时干己土刑克子水，乙时为误，故为己时。且看上下顺行以丙丁戊己庚辛壬癸，甲乙时不与焉，故为己时。

《韩国国学本五行精纪》、《国图瞿氏本五行精纪》、《国图张氏本五行精纪》皆作：亥人戊时。是以戌时为误，当为戊时。
